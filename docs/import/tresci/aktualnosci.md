# Aktualności

Strona bez własnej treści — w WordPressie ustawiona jako `page_for_posts` (lista wpisów).

Nagłówek listy pochodzi z `index.php`: eyebrow „Olimpiada Kwantowa”, h1 „Aktualności”.
Kafel wpisu: data `d.m.Y`, tytuł (link), zajawka skrócona do 28 słów.
Komunikat pustej listy: „Brak aktualności.”

Wpisy — patrz `docs/import/aktualnosci.md`.
